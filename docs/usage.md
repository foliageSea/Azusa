## 首次配置

1. 在「设置 → 文件服务器」新增 WebDAV 或 SMB 连接，测试后保存。保存不会自动切换，请回到文件管理页选择该连接。连接字段、代理和 SMB 限制见[文件服务器](file-servers.md)。
2. 如需 AI 整理，在「设置 → AI Agent」填写支持工具调用的 OpenAI 兼容模型、API Key 和 API 基础地址。默认地址是 `https://api.openai.com/v1`，不要填完整的 `/chat/completions` 地址。
3. 如需 AI 整理或元数据搜刮，在「设置 → TMDB」填写 API Key 或 API Read Access Token。AI、TMDB 和代理模式为全局配置，不随文件服务器切换。

日常使用的连接信息都在应用内配置，无需创建 `.env` 文件。`AZU_*` 环境变量仅用于[开发联调](development.md)。

### 命名语言与格式

在「设置 → TMDB」选择命名语言和格式，修改会自动保存，并在下一次生成整理建议时生效；不会改动已有预览或远程文件。命名语言独立于界面语言，默认简体中文，也可选 English。TMDB 没有对应译名时保留原名，不让 AI 自行翻译。

| 格式 | 电影示例 | 剧集示例 |
| --- | --- | --- |
| 标准（默认） | `片名 (2024).mkv` | `剧名 - S01E01 - 单集名称.mkv` |
| 简洁 | `片名 (2024).mkv` | `剧名 - S01E01.mkv` |
| 点分隔 | `片名.2024.mkv` | `剧名.S01E01.单集名称.mkv` |
| 点分隔-简洁 | `片名.2024.mkv` | `剧名.S01E01.mkv` |

AI 默认保留原扩展名和字幕语言标记；剧集特殊集使用 `S00`，电影不使用季集编号，多版本电影保留版本标记。缺少年份或单集名称时省略，不编造。实际建议仍需人工核对。

### 配置备份

在「设置 → 常规 → 配置备份」可按类别导出或导入 WebDAV／SMB 连接列表、TMDB 和 AI Agent 配置。默认导出不含密码或密钥的 JSON；勾选「包含凭据」后，必须设置至少 12 个字符的独立备份口令，整个文件使用 AES-256-GCM 加密。导入时需要同一口令，请妥善保管。桌面端通过保存对话框导出，移动端通过系统分享面板保存或发送备份文件。

导入会先显示预览，不自动测试连接。WebDAV 按地址和用户名跳过重复连接，SMB 按主机、共享、域和用户名去重，不删除或切换当前连接；TMDB 和 AI Agent 只覆盖选中的类别。备份缺少凭据时保留原有密钥，但 AI 地址变化时不能自动复用旧密钥。备份不包含全局代理地址和模式、收藏、历史或外观设置。

## AI 整理

1. 连接文件服务器，打开需要整理的电影、剧集或混合目录。
2. 在「文件管理」页打开目录，点击「整理此目录」；也可勾选多个目录，点击「整理所选目录」返回整理助手。支持跨层级选择、全选当前筛选列表中的目录和清空选择。点击助手顶部「已选 N 个目录」可展开管理面板，按父路径分组查看目录、展开完整路径、移除或添加目录。输入片名、年份、剧名、季数或目录结构等要求，也可选择快捷提示后补充要求再发送。
3. 默认启用「包含子目录」，递归扫描下层电影、剧集和各季目录；关闭后只分析当前目录。确认将扫描范围内的目录路径和文件名发送给配置的 AI 服务。
   多选时该开关作用于所有所选目录，递归扫描自动合并重叠的父子范围。每个目录独立分析并在各自范围内整理，建议汇总后统一预览和执行。
4. 等待 AI 查询 TMDB 并生成整理方案，在整理助手中按作品和季查看目录树，逐项核对匹配依据、目标目录与文件名。可追加要求重新生成方案。
5. 按需调整「电影独立文件夹」「剧集独立文件夹」「按季分文件夹」，这些开关会在本地重新规划目标路径，不再次调用 AI。编辑名称或排除不需要处理的文件，核对将新建的目录及文件变更后，点击「确认并执行」。
6. 查看执行结果和历史。历史区分移动、重命名、移动并重命名，并显示执行时的服务器名称和协议；旧记录没有服务器信息时显示 `-`。如中途失败，先刷新远程目录核对实际状态。

## 元数据搜刮与清理

### 搜刮元数据

1. 在「文件管理 → 搜刮 → 搜刮元数据」确认范围。默认带入已勾选的目录，未勾选时使用当前目录；可移除目录，点击目录名称可展开完整路径。如需添加目录，请回到文件管理页勾选。
2. 点击「开始扫描」，递归识别视频并匹配 TMDB。重叠的父子目录会合并，预览中显示本次的固定范围。扫描依据为文件名和所在文件夹名，支持点分隔命名、`Season 1` 等季目录和 `[tmdbid=123]`、`{tmdb-123}` 等编号标记，不上传视频内容。
3. 核对并勾选匹配项，再确认写入。应用写入 NFO；如不需要海报等图片，可关闭图片下载选项。

典型产物：

- 电影：`片名 (2014).nfo`、`片名 (2014)-poster.jpg`、`片名 (2014)-fanart.jpg`；
- 剧集：每集 `同名.nfo` 与 `同名-thumb.jpg`；只包含一部剧集的剧集文件夹（季文件夹的上一级）另写入 `tvshow.nfo`、`poster.jpg`、`fanart.jpg` 和 `season01-poster.jpg` 等季海报，混合目录不写剧集级文件。仅选择 `Season 1` 等季目录时，写入也限制在该季目录内，不会在所选范围外的上级剧集目录写入 `tvshow.nfo`、海报或背景图；需要这些剧集级文件时，请选择剧集目录。

已存在的同名文件会跳过且不覆盖；遇到失败立即停止。如需重建已有的搜刮文件，请先核对并清理旧文件。

### 清理搜刮文件

点击「搜刮 → 清理搜刮文件」，同样复用文件管理页的目录选择，确认范围并点击「开始扫描」，再扫描所选目录下的 NFO、`poster`/`fanart`/`banner`/`clearlogo` 等标准图片名、`seasonXX-poster` 季图片、与视频同名或以视频名加 `-poster`/`-fanart`/`-thumb` 等后缀命名的图片，以及 `extrafanart`、`extrathumbs`、`.actors` 中的图片，勾选后确认删除。删除前逐个重新检查，已变化或不存在的文件跳过。规则可能匹配发布组说明等非搜刮生成的 NFO，请核对后再删除；清理后留下的空文件夹可用「清理空目录」处理。

### 清理空目录

可在「文件管理」页点击「清理空目录」，扫描、勾选并确认删除遗留的空文件夹。嵌套空目录自底向上清理，所选目录本身不会删除。包含隐藏文件、字幕、封面或 NFO 的目录不算空目录；隐藏和系统文件夹不向下清理。删除前重新检查，非空则跳过，读取或删除失败则停止。清理期间请勿向目标目录写入文件，WebDAV 不保证“检查为空并删除”的原子性。

## 安全与限制

- AI 分析会发送所选目录路径、文件名及补充要求，**不会上传文件内容**；请确认这些信息可以交给你配置的服务处理。
- WebDAV／SMB 密码、AI Key 和 TMDB 凭据通过 `flutter_secure_storage` 保存在同一个 `azusa.credentials.v1` 安全存储条目中，内部使用带版本的 JSON，文件服务器密码按连接的凭据引用区分；凭据不会以明文写入普通文件或 SQLite。全局 AI、TMDB、代理配置及外观设置保存在本地偏好中。
- macOS 钥匙串中该条目的显示名称为「Azusa 凭据」，Service（服务标识）为 `com.foliage.azusa.credentials`，Account（条目键）为 `azusa.credentials.v1`；两者共同定位同一个 JSON 条目。
- 应用只访问当前凭据仓库，不再读取、迁移或删除旧开发版的钥匙串服务及独立凭据；仅保存在旧存储中的凭据需重新填写，旧条目可手动清理。当前仓库不存在时初始化为空，后续启动只读取一个安全存储条目，同一会话复用内存缓存。拒绝授权后不会自动重复请求，可在设置加载错误处手动重试。单条目存储不保证消除 macOS 因签名或钥匙串信任问题导致的跨启动授权。
- 文件服务器连接列表、当前连接选择、执行历史、AI 用量和目录收藏保存在应用支持目录下的 `azusa.sqlite3` 中。
- AI 整理默认递归扫描所选目录，按上层作品目录分组，每批最多 100 个视频，汇总建议后统一预览与确认。视频同目录下唯一匹配的同名字幕可随视频整理，其他文件留在原处。
- 子文件夹中的剧集视频和匹配的字幕可平铺到所选整理目录，也可按方案移入作品或季目录；电影可按方案移入独立作品目录。所需目录在执行时创建，原文件夹保留。执行前会校验冲突，并在每项操作前重新检查源文件和目标文件。
- 批量操作不是事务：遇到失败立即停止，已经完成的修改不会自动回滚。
- HTTP 可用于本地联调，但不提供传输加密；实际服务建议使用 HTTPS。
- AI 用量支持按时间、模型和状态筛选。Token 用量与费用估算依赖服务返回的数据和可用价格，不能作为最终账单依据。
