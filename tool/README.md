# 本地 WebDAV 测试数据

所有视频均为小体积文本占位文件，不能播放，不包含真实影视内容。

## 启动服务

在项目根目录运行（依赖已安装时可跳过前两步）：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r tool/webdav-requirements.txt
.venv/bin/python tool/local_webdav.py
```

连接信息：

- 地址：`http://127.0.0.1:18765/dav/`
- 用户名：`azu`
- 密码：`azu-local-test`

服务只监听本机。其他设备上的应用无法通过此地址连接。
启动时会打印 `workspace`（数据目录）和 `request_log`（请求日志）。

## 数据目录

| 目录 | 内容与用途 |
| --- | --- |
| `剧集测试` | 原有绝命毒师第一季 3 个视频、字幕和中文路径样例 |
| `操作测试` | 空目录，供上传、下载、移动、重命名测试 |
| `批量整理测试` | 绝命毒师、风骚律师，各 2 季，每季 3 集，共 12 个视频、4 个唯一同名字幕；每季额外嵌套一层发布组目录 |
| `空目录清理测试` | 单层及嵌套空目录，以及隐藏文件、NFO、字幕、普通文件、隐藏目录和回收站保护样例 |

### 验证递归批量整理

1. 在应用打开 `批量整理测试`，启用「包含子目录」。
2. 选择「按作品建立文件夹并分季整理」，生成建议。
3. 检查 12 个视频和 4 个配对字幕；确认后执行。
4. 文件应整理到所选目录下的剧名／季目录，原 `说明.txt` 保留。

该数据集用于验证多剧、多季及递归扫描，未超过每批 100 个视频的拆批阈值。

### 验证空目录清理

在应用打开 `空目录清理测试`，点击「清理空目录」：

- 初次扫描应发现 **5 个**可删除目录：单层 1 个、嵌套树 3 个、普通文件目录下的空子目录 1 个。
- 含隐藏文件、NFO、字幕和普通文件的目录必须保留。
- 隐藏目录、`#recycle` 及包含它们的父目录必须保留。
- 取消勾选嵌套树的叶目录后，父目录仍非空，应在执行时跳过。
- 可在扫描预览后，向某个待清理目录写入文件，再确认清理，验证该目录会被跳过。
- 所选 `空目录清理测试` 本身不会删除。

## 恢复测试数据

每次启动会创建独立的新数据集。已有服务可使用启动时打印的真实 `workspace` 路径重置：

```bash
python3 tool/reset_webdav.py /tmp/opencode/azu-webdav-实际目录名
```

该操作需要确认，会清空该测试工作目录的 `share`，然后重新生成全部样例；不会清空请求日志或服务信息。请先停止应用中的整理与清理操作。

## 生成到自选目录

无需启动 WebDAV 或安装依赖，可在项目根目录使用标准库生成：

```bash
python3 -c 'from pathlib import Path; from tool.reset_webdav import create_fixture; create_fixture(Path("/tmp/opencode/azu-fixture-manual"))'
```

目标必须是尚不存在的新目录。然后将该目录通过自己的 WebDAV 服务共享。
